📥 The Dataset Arrives

You receive the following campus facilities table.

Your task is to inspect it before anyone uses it for mapping or analysis.

F002 computer laboratory FTMK 35 Hang Tuah Jaya

F004 Computer Lab FTKE 40 —

The highlighted cells are clues — but you must decide what the problems mean.

1 Spot the Consistency Problem

Look at the Facility Type field.

What is the main problem?

✓ Correct.

Computer Lab, computer laboratory and COMP LAB may describe the same category. Using consistent values will make classification, querying and analysis more reliable.
Not quite.

Compare how the same type of facility has been recorded in different rows.
2 Check the Capacity

Most capacity values are numbers: 40, 35, 40.

But one record contains: Thirty.

What should you notice?

✓ Correct.

If capacity is intended to represent a number, the values should be recorded consistently.
Not quite.

Think about how GIS may later need to compare, calculate or analyse these capacity values.
3 Find the Duplicate

Two rows use the same identifier: F004.

What should you do first?

✓ Correct.

A repeated identifier may indicate a duplicate, but you should investigate before deleting or changing anything.
Not quite.

A repeated identifier is a warning. First determine whether the records actually represent the same real-world feature.
4 Can We Locate Every Record?

The F004 record has no address.

What does this mean?

✓ Correct.

Missing location information does not mean the facility does not exist. It means you may need another source before you can confidently locate it.
Not quite.

Remember what you learned in 04 LEARN — Geocoding. A location description must be sufficient for a reliable geographic match.
5 Should You Guess the Missing Value?

Suppose a capacity value is blank.

What is the best action?

✓ Correct.

Missing does not automatically mean zero. You should not invent a value simply to make the dataset look complete.
Not quite.

Do not invent information. A missing value should be investigated using an appropriate source.

💡 Data Creator Takeaway

Preparing data does not mean changing values until the dataset looks perfect.

It means recognising problems, checking them against appropriate evidence, and making careful decisions before the data are used for mapping or analysis.

Never “fix” geographic data by guessing.
