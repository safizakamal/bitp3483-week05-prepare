What should you consider using?

CONNECTING DATA

Finding the Common Link

A building GIS layer contains:

Building_ID · Students · Computers

Which field is most useful for connecting the corresponding information?

✓ Correct. Building_ID provides a common identifier that can connect corresponding records.
Not quite. Look for the value that appears in both datasets and identifies the same real-world building.

💡 The Week 5 Big Picture

Preparing geographic data is a journey.

Sometimes you need to create a feature from imagery.

Sometimes you need to locate records from addresses.

Sometimes information from different sources needs to be connected.

And before data are used, they need to be inspected, prepared and checked.

The goal is not simply to put information on a map. The goal is to create data that are fit for their intended GIS purpose.
